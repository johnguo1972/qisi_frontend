## ⚠️ 注意事项

### 1. 某些表可能没有 Django 模型定义

如果执行 `makemigrations` 时提示 "No changes detected"：
- 说明该表没有对应的 Django 模型
- 需要手动创建模型定义或保持现状

### 2. 服务器迁移记录冲突

如果服务器已有迁移记录：
```bash
# 检查服务器迁移状态
python manage.py showmigrations

# 标记已应用的迁移（避免重复执行）
python manage.py migrate --fake <app> <migration_name>
```

### 3. 外键依赖

确保所有依赖的表都已创建：
- Django 会自动处理外键顺序
- 如果外键失败，检查关联的表是否存在
