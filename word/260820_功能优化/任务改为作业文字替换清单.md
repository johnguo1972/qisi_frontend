# UniApp“任务”统一调整为“作业”文字替换清单

## 1. 文档说明

本文档用于指导后续统一调整 UniApp 中与作业业务相关的“任务”文案。

本次只整理替换位置和替换建议，不直接修改业务代码。后续执行替换时，应以当前代码实际内容为准，并重新核对行号。

检索范围：`uniapp/src`

当前检索结果：

- 命中文件：20 个
- 命中文字或注释：79 处
- 本文档重点整理：12 个作业业务相关文件
- AI 处理任务、导入任务、变式题后台任务不纳入普通“作业”文案替换

## 2. 统一替换原则

### 2.1 作业业务文案

以下场景中的“任务”统一调整为“作业”：

- 创建任务 → 创建作业
- 任务详情 → 作业详情
- 今日任务 → 今日作业
- 我的任务 → 我的作业
- 任务列表 → 作业列表
- 任务名称 → 作业名称
- 发布任务 → 发布作业
- 开始任务 → 开始作业
- 克隆任务 → 克隆作业
- 删除任务 → 删除作业
- 任务数据 → 作业数据
- 任务加载失败 → 作业加载失败

不能只做单字替换的场景，应保持完整语句通顺，例如：

- 暂无任务，等待老师发布吧 → 暂无作业，等待老师发布吧
- 查看孩子的学习任务和完成进度 → 查看孩子的作业和完成进度
- 正在加载孩子的学习任务 → 正在加载孩子的作业

### 2.2 不应替换的后台任务文案

以下“任务”不是教师布置的作业，不应统一替换：

- AI 任务处理中
- 变式任务等待超时
- 变式任务已失效
- 导入任务已提交
- 同类题生成任务
- AI 后台任务轮询
