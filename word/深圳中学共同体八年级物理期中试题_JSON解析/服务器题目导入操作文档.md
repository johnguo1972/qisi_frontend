## 3. 导入流程

服务器收到 ZIP 后，会解压并读取 all_questions.json，创建 ExamPaper 和 ExamQuestion，创建选择题选项，复制 assets/ 中的题图/公式图片，并将题目状态写为 json_imported。接口使用的临时目录在完成后会自动删除，因此原始 ZIP 要保留在 import_staging 中。

检查题目包结构和数量：

```
python - "$ZIP" <<'PY'
import json, sys, zipfile

with zipfile.ZipFile(sys.argv[1]) as zf:
    names = set(zf.namelist())
    root = next(n.split('/', 1)[0] for n in names if '/' in n)
    manifest = json.loads(zf.read(f'{root}/manifest.json'))
    package = json.loads(zf.read(f'{root}/all_questions.json'))
    questions = package.get('questions', [])
    qfiles = [n for n in names if '/questions/' in n and n.endswith('.json')]
    assets = [n for n in names if '/assets/' in n and not n.endswith('/')]
    print('paper_id:', manifest.get('paper', {}).get('paper_id'))
    print('questions:', len(questions))
    print('question_json_files:', len(qfiles))
    print('assets:', len(assets))
    if len(questions) != 20 or len(qfiles) != 20:
        raise SystemExit('题目数量或题目 JSON 文件数量不符合预期')
print('ZIP 检查通过')
PY
```

预期结果：题目 20 道、题目 JSON 文件 20 个、资源文件约 55 个。

## 7. 触发导入

接口需要教师账号的 Bearer Token。先在教师端登录，从浏览器本地存储取得 accessToken，然后在服务器执行：

```
read -rsp "请输入教师账号 access token: " TOKEN
echo
```

通过服务器本机接口导入：

```
curl --fail-with-body -X POST -H "Authorization: Bearer $TOKEN" -F "file=@$ZIP" http://127.0.0.1:8001/api/v1/questions/import-json-package
```

如果本机端口不可用，改用生产域名：

```
curl --fail-with-body -X POST -H "Authorization: Bearer $TOKEN" -F "file=@$ZIP" https://qisi.chengxuelu.com/api/v1/questions/import-json-package
```

成功响应应包含 code=0、imported=20、errors=0。完成后清除 Token：

```
unset TOKEN
```

## 8. 导入后校验

查询试卷：

```
sudo docker exec app-pgsql psql -U appuser -d appdb -c "SELECT id,title,subject,grade,paper_type,total_questions,status,created_at FROM public.tiku_exam_paper WHERE title ILIKE '%初二年级物理%' ORDER BY created_at DESC;"
```

查询题目状态：

```
sudo docker exec app-pgsql psql -U appuser -d appdb -c "SELECT p.title,q.parse_status,COUNT(*) AS question_count FROM public.tiku_exam_paper p JOIN public.tiku_exam_question q ON q.paper_id=p.id WHERE p.title ILIKE '%初二年级物理%' GROUP BY p.title,q.parse_status;"
```

判定标准：题目 20 道，paper_type=json_import，parse_status=json_imported，选项、题图和公式图片数量正常，并且教师端可以打开题目详情。

## 9. 日志和注意事项

查看日志：

```
tail -n 100 /mnt/datadisk0/qisi/logs/gunicorn-error.log
```

不要使用以下脚本导入本题库：

```
word/sql/导入题目数据_脚本_v2.py
```

该脚本只支持 MySQL INSERT INTO ... VALUES，不读取本题库 ZIP。import_large_question_zip 面向 JSON 数组格式，import_g9_autumn_practice 固定针对九年级 277 题包，均不适用本题库。

导入成功后，应在教师端抽查题干、选项、答案、解析、题图和公式图片。
