### 3.2 图片路径解析验证


1. 取 `file` 字段的 `basename` → `q13_tuning_fork.png`
2. 在 `assets/` 目录中查找该文件
3. 复制到 `media/exams/json_imports/{paper_id}/`
4. 在 `QuestionImage` 中记录相对路径

**验证结果**：✅ 路径解析逻辑正确

### 5.2 数据流验证

```
用户操作 → 页面方法 → API调用 → 后端视图 → 数据库
    │                                          │
    │              响应数据 ←──────────────────┘
    │                  │
    └── 状态更新 → 视图刷新
```

**具体数据流**：

1. **知识树加载**: `onMounted()` → `knowledgeApi.getTree()` → `dict_views.knowledge_points()` → `KnowledgePoint` 表 → 树形渲染
2. **题目加载**: `loadQuestions()` → `questionApi.list(params)` → `question_views.question_list()` → `ExamQuestion` 表 → 卡片渲染
3. **JSON导入**: 用户选ZIP → `importJsonPackage(formData)` → `json_import_views.import_json_package()` → 解压/解析/入库 → 返回结果 → 刷新列表
4. **拍照导入**: 点击拍照 → 跳转 `photo-upload.vue` → `photo_views.photo_create_question()` → AI识别 → 创建题目 → 跳转编辑

## 6. 边界情况验证

### 6.1 JSON导入边界情况

| 场景 | 处理方式 | 验证状态 |
|------|----------|----------|
| ZIP文件损坏 | `zipfile.BadZipFile` → 返回错误信息 | ✅ |
| ZIP包含恶意路径 (`../`) | 解压前检查 → 拒绝并报错 | ✅ |
| JSON格式错误 | `json.JSONDecodeError` → 跳过该题并记录 | ✅ |
| 图片文件不存在 | 记录警告日志，继续导入下一题 | ✅ |
| 题目类型未知 | 映射为 `unknown` | ✅ |
| 超大ZIP文件 (>50MB) | 拒绝上传 | ✅ |
| 空ZIP文件 | 检测无题目数据 → 报错 | ✅ |
| 重复导入相同数据 | 创建新Paper，不检查重复（可接受） | ✅ |
| JSON中无 `paper` 字段 | 使用默认值 | ✅ |
| 子问题嵌套 | 前端展示子问题列表 | ✅ |

### 6.2 前端边界情况

| 场景 | 处理方式 | 验证状态 |
|------|----------|----------|
| 知识树加载失败 | Toast提示 + 显示空状态 | ✅ |
| 题目列表为空 | 显示"暂无题目"提示 | ✅ |
| 图片加载失败 | 显示占位图 | ✅ |
| KaTeX渲染失败 | 显示原始文本 | ✅ |
| 网络断开 | 请求失败 + Toast提示 | ✅ |
| 导入过程中关闭页面 | 后台任务继续，返回可查看历史 | ✅ |
