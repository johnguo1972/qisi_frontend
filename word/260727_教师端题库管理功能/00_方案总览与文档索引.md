## 数据库变更速查

### 新增表（3张）

| 表名 | Django模型 | 用途 |
|------|-----------|------|
| `tiku_question_basket` | `QuestionBasket` | 题目篮子（购物车） |
| `tiku_question_tag` | `QuestionTag` | 自定义标签 |
| `tiku_question_tag_relation` | `QuestionTagRelation` | 题目-标签关联 |

### 现有表新增字段（1张表，6个字段）

**`tiku_exam_question` 表新增：**

| 字段 | 类型 | 用途 |
|------|------|------|
| `tags` | JSONField | 自定义标签列表 |
| `source_collection` | CharField(255) | 来源题集名称 |
| `creator_name` | CharField(100) | 创建者姓名 |
| `collected_at` | DateTimeField | 收录日期 |
| `video_explanation_url` | CharField(500) | 视频解析URL（预留） |
| `barcode_data` | CharField(100) | 条形码编码值（预留） |

## 团队协作快速指南

### 开发者A（做变更）

```bash
# 1. 改模型
# 编辑 apps/study/models.py 和 apps/parser/models.py

# 2. 生成迁移
python manage.py makemigrations study parser

# 3. 本地执行迁移
python manage.py migrate

# 4. 提交代码（包含迁移文件！）
git add apps/study/migrations/ apps/parser/migrations/
git commit -m "feat: 题库管理功能数据库变更"
git push
```

### 开发者B（拉取代码）

```bash
# 1. 拉取代码
git pull

# 2. 执行迁移
python manage.py migrate

# 3. 验证
python manage.py showmigrations study parser
```

### 服务器部署

```bash
# 1. 拉取代码
git pull origin main

# 2. 安装新依赖
pip install python-barcode Pillow

# 3. 执行迁移
python manage.py migrate --noinput

# 4. 重启服务
sudo systemctl restart qisi
```

## 关键决策记录

| 决策 | 理由 |
|------|------|
| 标签使用JSONField存储在ExamQuestion上 | 简单高效，避免复杂关联查询 |
| 同时维护QuestionTag独立表 | 支持标签管理（CRUD）、统计题目数、热门标签推荐 |
| 条形码使用Code128格式 | 支持字母+数字，长度适中，扫描识别率高 |
| 视频解析预留URL字段 | 不阻塞当前开发，后续接入视频服务 |
| JSON导入复用ParseTask记录进度 | 复用现有任务系统，前端可统一展示进度 |
| 题目篮子独立表 | 支持多用户隔离，避免JSONField的并发问题 |

## 风险评估

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|----------|
| 迁移文件冲突 | 中 | 中 | 遵循迁移管理规则，冲突时重新生成 |
| JSON导入大文件超时 | 低 | 高 | 限制50MB，异步处理，进度可查 |
| 标签系统性能 | 低 | 低 | 标签数量有限（<1000），JSONField查询快 |
| 条形码图片生成慢 | 低 | 低 | python-barcode生成<100ms，可缓存 |
