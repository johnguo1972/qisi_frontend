# 错题精练生成功能总结

## 1. 功能目标

针对线下布置练习、未发布线上作业或未导入学生错题统计的课堂，系统可依据课堂练习题、错题练习题和映射关系，为课堂学生生成个人错题精练题及 PDF。

## 2. 题号和映射规则

映射表统一使用：

```text
练习题号    错题题号
```

- 练习题号：当前课堂练习题/原题题号；
- 错题题号：错题练习 DOCX 中的题号。

服务端内部继续使用 `workbook_question_no` 和 `wrong_question_no` 保存数据，但前端展示和编辑顺序与 Excel 保持一致。

## 3. 无学生统计时的处理

当没有线上答题记录、也没有导入学生错题统计时：

1. 从当前课程的课堂练习题关联中构造统计题目列表；
2. 根据练习题号解析原练习题 ID；
3. 根据有效映射找到对应的错题练习题；
4. 为课堂每名有效学生创建默认错题单元格；
5. 页面中对应题号显示错题叉号；
6. 生成时按映射关系为每名学生生成精练题。

默认记录复用现有 `TeacherWrongBookCell`，使用 `mark_source='import'`，避免新增数据库字段和迁移；重复刷新或生成不会创建重复记录。

## 4. 后端实现

### 4.1 课堂题目范围

在线下课堂上下文 `course_offline_wrongbook` 下，统计矩阵从当前课程未删除的 `CourseQuestionLink` 获取课堂练习题，并写入矩阵题目范围。无课程节点的线下题目允许进入统计范围。

### 4.2 映射题号解析

映射导入时优先使用线上 `MissionQuestionRel` 解析原题；无线上练习时，回退到当前课程的 `CourseQuestionLink`。映射关系必须绑定到有效的原练习题 ID，才能参与统计和生成。

### 4.3 默认错题记录

统计接口在无线上下文时检查当前已就绪的错题练习题源和有效映射，为每名课堂学生与原练习题建立错题记录。记录使用唯一约束保证幂等。

### 4.4 精练题生成

统一调用：

```text
POST /api/v1/missions/{mission_id}/classroom-wrongbook-statistics/wrong-drill/generate
```

服务端根据学生错题记录匹配原题，再通过映射找到错题练习题，异步生成个人精练题、个人作业和 PDF。生成任务由 Celery 执行，并保留批次、学生包和失败原因。

## 5. 前端功能

### 5.1 错题统计页面

- `wrong_count=0` 时，如果存在有效错题练习和映射，不再直接拦截生成；
- 无线上练习时显示课堂练习题号；
- 默认错题记录显示为错题叉号；
- 支持全部学生或选中学生生成；
- 生成任务完成后弹窗显示生成数量和失败数量。

### 5.2 错题映射页面

- 表格列顺序为“练习题号、错题题号”；
- 支持导入、编辑、保存和导入历史；
- 右侧增加“生成精练题”按钮；
- 默认按当前课堂全部学生生成；
- 复用错题统计页的生成接口和后端任务；
- 生成后显示结果弹窗。

### 5.3 生成结果弹窗

弹窗内容包括：

- 成功生成的学生数量；
- 失败数量及状态提示；
- 教师端查看路径：`工作台 → 作业列表 → 错题精练 → 查看`；
- 学生端查看路径：`我的作业 → 错题精练`；
- 点击“确认”关闭弹窗。

异步任务提交时先提示任务已提交，任务完成后通过轮询展示最终生成结果。

## 6. 教师端和学生端查看位置

- 教师端：工作台作业列表中，题目来源显示为“错题精练”，点击“查看”进入作业详情；
- 学生端：学生“我的作业”列表中显示个人错题精练作业，点击进入答题；
- 教师端错题统计页和错题映射页可查看生成状态、学生数量及 PDF 入口。

## 7. 兼容性和风险控制

- 已发布线上作业仍使用原有线上统计和生成流程；
- 默认线下错题仅用于 `course_offline_wrongbook` 上下文；
- 无效映射、找不到原题或错题练习题的行不参与生成；
- 生成批次和历史 PDF 保持不可变；
- 当前线下题目按课程的 `CourseQuestionLink` 获取，若同一课程包含多个课堂的题目，后续应进一步增加课堂级来源筛选。

## 10. 有真实学生错题统计时的生成规则

当老师已经通过手动统计或 Excel 导入，为学生建立了真实错题记录，同时存在错题练习和映射关系时，系统应严格按照每个学生自己的错题记录生成个人精练题：

```text
学生 A 的错题 → 映射 → 学生 A 的精练题
学生 B 的错题 → 映射 → 学生 B 的精练题
```

后端生成任务按学生分别读取 `TeacherWrongBookCell`，每名学生生成独立的精练题包和 PDF，不应将不同学生的错题合并。

默认错题模式的优先级规则：

1. 全班没有真实错题统计时，才按有效映射为每名学生默认标记全部练习题；
2. 存在真实统计时，真实统计优先，不能用默认映射覆盖或补齐已有学生的统计；
3. 若部分学生有真实统计、部分学生没有，应明确采用“按学生判断”的策略：有真实统计的学生使用自己的记录，没有真实统计的学生才使用默认映射；
4. 真实记录与默认记录应通过来源字段区分，便于审计和后续覆盖。

实现时必须在默认记录创建逻辑中增加优先级判断，不能仅以课堂处于线下模式且映射为 `ready` 就为所有学生补齐默认错题。否则会导致老师只统计部分学生时，其他映射题被错误追加到已有真实统计的学生中。
