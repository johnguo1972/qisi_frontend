# 错题精练生成优化实施方案

## 1. 目标与适用场景

当课堂没有发布线上练习，且没有导入学生错题统计时，只要已导入错题练习 DOCX、映射关系表状态为 `ready`，系统即可依据映射关系为课堂所有学生生成精练题。已有线上作业和真实错题统计的流程保持不变。

## 2. 题号及映射约定

映射表固定使用以下列顺序：

```text
练习题号    错题题号
```

“练习题号”是原练习册/练习题题号；“错题题号”是错题练习 DOCX 中的题号。服务端内部字段可继续使用 `workbook_question_no` 和 `wrong_question_no`，但导入、展示、编辑和保存必须保持该业务含义一致。

## 3. 无线上作业时的原题来源

不能仅依赖 `MissionQuestionRel` 查找原题，因为未发布线上练习时可能没有该记录。线下题源统一使用“当前课堂练习题”，即已导入并归属于当前课堂/课程的课堂练习题，不另建独立题源模型。

题源必须提供唯一关系：

```text
练习题号 → ExamQuestion.id
```

匹配必须限定在当前课程/课堂范围内，优先使用当前课堂练习题记录（如 `CourseQuestionLink` 及其关联题目）按题号解析，避免不同文档同号题串题。课堂练习题应保留来源文档和题号，以便审计和重新导入。

## 4. 映射导入和编辑校验

导入或保存映射时：

1. 读取两列并按表头确定语义，不按列位置硬编码；
2. 校验错题题号存在于错题练习 DOCX；
3. 将练习题号解析为当前线下题源中的 `ExamQuestion.id`；
4. 对原题不存在、题号重复、题源不属于当前课堂的行返回逐行错误；
5. 只有解析出原题 ID 和错题练习题 ID 的行才可参与生成；
6. 支持部分成功时显示有效/无效数量，无效行不得进入统计和生成。

## 5. 统计页面默认展示和默认错题

无线上练习题时，统计接口从有效映射和线下题源构造完整练习题号列表，不再显示空题号列。没有学生统计时，为每个有效学生和每个有效原题创建或更新 `TeacherWrongBookCell`，使用专用来源标识（如 `offline_import_default`）。

默认记录必须幂等，不能覆盖真实统计；真实统计导入后按规则覆盖或区分默认记录。页面应明确显示“线下导入默认”，避免误认为线上作答结果。

## 6. 精练题生成逻辑

前端不能仅因 `wrong_count === 0` 阻止生成。后端生成前统一校验：存在有效学生、题源和映射均为 `ready`、至少有一条有效映射，且存在真实错题记录或可创建默认记录。随后复用现有生成任务：

```text
学生错题记录 → 原练习题 ID → 映射关系 → 错题练习题 → 个人精练题/PDF
```

重复点击、刷新和重试必须幂等；历史任务和已生成 PDF 保持不可变。

## 7. 错题映射页面增加生成入口

在 `classroom-wrong-mapping.vue` 右侧增加“生成精练题”按钮：

- 默认面向当前课堂全部学生；
- 复用错题统计页面的生成接口和 Celery 任务，不复制业务逻辑；
- 生成前检查题源、映射、学生和原题 ID；
- 无学生统计时自动执行第 5 节默认错题逻辑；
- 显示排队中、生成中、成功、部分失败、失败状态及历史；
- 生成前提示“将按导入映射为所有学生默认标记错题”。

错题统计页面和错题映射页面的生成结果、错误码、进度和 PDF 入口必须保持一致。

## 8. 验收标准

- 无线上练习时显示全部有效练习题号；
- 映射每行均可解析原题 ID 和错题练习题 ID；
- 无学生统计时每名学生默认显示错题叉号；
- 两个页面均可为全部学生生成精练题；
- 无效映射显示行级错误且不生成题目；
- 重复生成不产生重复错题或精练题；
- 真实统计导入后能够覆盖或区分默认标记；
- 已有线上作业场景回归正常。
