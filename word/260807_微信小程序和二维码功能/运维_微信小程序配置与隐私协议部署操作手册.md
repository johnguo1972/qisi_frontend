- 服务域名：`https://qisi.chengxuelu.com`
- 隐私协议地址：`https://qisi.chengxuelu.com/privacy`

- Nginx 容器：`qisi-nginx`

## 2. 部署隐私协议页面

将项目中的 `privacy/index.html` 上传到服务器：

```bash
sudo mkdir -p /mnt/datadisk0/qisi/frontend-h5/privacy
sudo cp privacy/index.html /mnt/datadisk0/qisi/frontend-h5/privacy/index.html
sudo chmod 755 /mnt/datadisk0/qisi/frontend-h5/privacy
sudo chmod 644 /mnt/datadisk0/qisi/frontend-h5/privacy/index.html
```

如果 Nginx 容器不能访问该目录，确认容器存在挂载：

```bash
sudo docker inspect qisi-nginx --format='{{json .HostConfig.Binds}}'
```

应包含：

```text
/mnt/datadisk0/qisi/frontend-h5:/var/www/qisi-frontend-h5
```

现有 HTTPS server block 中增加：

```nginx
location = /privacy { return 301 /privacy/; }
location /privacy/ {
    alias /var/www/qisi-frontend-h5/privacy/;
    index index.html;
    try_files $uri $uri/ /privacy/index.html;
}
```

检查并平滑重载：

```bash
sudo docker exec qisi-nginx nginx -t
sudo docker exec qisi-nginx nginx -s reload
curl --fail --show-error --silent https://qisi.chengxuelu.com/privacy/ -o /dev/null
```

## 3. 配置 AppSecret

在微信公众平台进入：

```text
开发 → 开发管理 → 开发设置 → AppSecret
```

生成或重置 AppSecret。然后在服务器执行：

```bash
cd /mnt/datadisk0/qisi/frontend-h5/word/260807_微信小程序和二维码功能
chmod +x 生产环境微信配置与二维码发布.sh
sudo ./生产环境微信配置与二维码发布.sh
```

输入 AppID 和 AppSecret。脚本会备份 `.env`、写入环境变量、执行 Django 检查、迁移并重启服务。禁止将 AppSecret 写入前端、Git、日志或工单。

验证：

```bash
cd /mnt/datadisk0/qisi/backend
venv/bin/python manage.py shell -c "from django.conf import settings; print(settings.WECHAT_MP_APPID); print(bool(settings.WECHAT_MP_APPSECRET))"
```

## 4. 微信公众平台设置

### 4.1 业务域名、request 合法域名和 uploadFile 合法域名

在“开发管理 → 开发设置 → 服务器域名”中确认：

```text
request 合法域名： https://qisi.chengxuelu.com
uploadFile 合法域名： https://qisi.chengxuelu.com
```

不要填写带路径的地址，不要填写 HTTP 地址或本地地址。

### 4.2 隐私保护指引

在“设置 → 基本设置 → 用户隐私保护指引”中填写并发布：

```text
隐私协议 URL：https://qisi.chengxuelu.com/privacy
```

收集目的应覆盖：手机号、微信登录身份、学习记录、答题图片、设备日志、家长代理关系。权限用途应覆盖摄像头和相册，不要声明项目未使用的定位权限。

### 4.3 服务类目

在“设置 → 基本设置 → 服务类目 → 添加服务类目”中，根据主体资质选择实际可用的教育/在线教育相关类目。若后台要求资质，上传营业执照和教育相关证明；不得选择与实际业务不符的类目。

### 4.4 账号信息

确认小程序名称、头像、主体、管理员、客服联系方式和主体认证状态均已完成。登录方式仍须保留手机号验证码登录，不能仅提供微信登录。

## 5. 微信开发者工具与真机验收

1. 使用 `uniapp/dist/build/mp-weixin` 导入微信开发者工具。
2. AppID 填写 `wx86647a750a7727cb`。
3. 关闭“不校验合法域名”后测试真实接口。
4. 使用 iOS 和 Android 各一台真实设备测试：微信登录、手机号绑定、扫码、6位作业码、任务加载、答题图片上传、错题、成长、家长切换孩子和退出登录。
5. 体验版测试通过后，上传版本并提交审核。

## 6. 回滚

隐私页面回滚前备份：

```bash
sudo cp -a /mnt/datadisk0/qisi/frontend-h5/privacy /mnt/datadisk0/qisi/frontend-h5/privacy.bak.$(date +%Y%m%d_%H%M%S)
```

Nginx 配置修改前备份 `/opt/qisi/nginx.conf`，任何修改后必须先执行 `nginx -t`，通过后再 reload。
