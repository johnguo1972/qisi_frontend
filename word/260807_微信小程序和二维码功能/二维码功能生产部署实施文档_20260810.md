## 八、服务和 Nginx

```bash
sudo systemctl restart qisi-gunicorn
sudo systemctl restart qisi-celery
sudo systemctl restart qisi-celery-beat

sudo systemctl is-active qisi-gunicorn
sudo systemctl is-active qisi-celery
sudo systemctl is-active qisi-celery-beat

sudo nginx -t
sudo systemctl reload nginx
```

Nginx 必须包含二维码 H5 中转：

```nginx
location ~ ^/hw/([ABCDEFGHJKMNPQRSTUVWXYZ23456789]{6})$ {
    return 302 /#/pages/student/scan-entry?code=$1;
}

location ~ ^/paper/([ABCDEFGHJKMNPQRSTUVWXYZ23456789]{8})/([ABCDEFGHJKMNPQRSTUVWXYZ23456789]{6})/p([0-9]+)$ {
    return 302 /#/pages/student/scan-entry?student_code=$1&code=$2&page=$3;
}
```

二维码规则必须放在通用 `location /` 之前，并且不能代理到本地开发端口 `5273`。

## 十二、当前已知门禁

- 生产微信 AppSecret 必须使用新生成的密钥，不能继续使用已经公开的旧密钥。
- 微信公众平台 request、uploadFile、downloadFile 和业务域名必须配置。
- 真机扫码需要在微信开发者工具构建后导入并测试，不能仅用浏览器 5273 端口替代。
- 服务器后端必须先更新到包含 `apps/qrcode` 和微信 settings 的版本，再执行迁移和重启。
