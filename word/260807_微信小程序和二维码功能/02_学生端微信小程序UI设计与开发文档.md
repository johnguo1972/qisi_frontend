## 一、文档目标

本文档为学生端微信小程序的专项开发指南，核心解决：

1. **布局适配**：平板端"左侧菜单栏+右侧内容区"如何适配手机端窄屏
2. **交互重设计**：针对手机端操作习惯重新设计页面交互
3. **代码组织**：小程序端独立代码文件，不影响 App/H5 端现有功能
4. **开发规范**：条件编译策略、组件复用方式、样式规范

### 2.5 media-url.ts 小程序端条件编译

修改 `uniapp/src/utils/media-url.ts`：

```typescript
export function getMediaUrl(path: string): string {
  if (!path) return ''
  if (/^(https?:\/\/|data:|blob:)/i.test(path)) return path
  // #ifdef MP-WEIXIN
  const relative = path.replace(/^\/+/, '').replace(/^media\//i, '')
  return `https://qisi.chengxuelu.com/media/${relative}`
  // #endif
  // #ifdef APP-PLUS
  const relative = path.replace(/^\/+/, '').replace(/^media\//i, '')
  return `https://qisi.chengxuelu.com/media/${relative}`
  // #endif
  // #ifdef H5
  const relative = path.replace(/^\/+/, '').replace(/^media\//i, '')
  return `/media/${relative}`
  // #endif
}
```

### 2.6 image-upload.ts 小程序端适配

现有 `image-upload.ts` 中 H5 使用 `document.createElement('input')`，小程序端需适配。学生答题图片必须在 `answer.vue` 创建 `attempt_id` 后上传到学生 attempt 接口，不能调用 `/questions/upload-image/`：

```typescript
// 在 image-upload.ts 中添加小程序端分支
export async function chooseAndUpload(options: {
  count?: number
  sourceType?: Array<'camera' | 'album'>
  attemptId: string
}): Promise<string[]> {
  // #ifdef MP-WEIXIN
  return new Promise((resolve, reject) => {
    wx.chooseMedia({
      count: options.count || 9,
      mediaType: ['image'],
      sourceType: options.sourceType || ['camera', 'album'],
      success: async (res) => {
        const urls: string[] = []
        for (const file of res.tempFiles) {
          const result = await uploadImage({
            filePath: file.tempFilePath,
            uploadUrl: `https://qisi.chengxuelu.com/api/v1/student/attempts/${options.attemptId}/upload-images`,
            fieldName: 'images',
          })
          if (result.statusCode < 200 || result.statusCode >= 300 || result.data?.code !== 0) {
            throw new Error(result.data?.message || '图片上传失败')
          }
          urls.push(...(result.data?.data?.images || []).map((item: any) => item.url))
        }
        resolve(urls)
      },
      fail: reject,
    })
  })
  // #endif

  // #ifdef APP-PLUS
  // ... 原有 App 逻辑
  // #endif

  // #ifdef H5
  // ... 原有 H5 逻辑
  // #endif
}
```

### 2.7 三端入口分流

当前 `App.vue` 和登录页会把学生/家长统一跳转到 `pages/student/layout`。v1.2 必须增加 MP-WEIXIN 分支：

```typescript
// #ifdef MP-WEIXIN

// #ifndef MP-WEIXIN
```


**适用设备**：平板（iPad/Android Pad）、PC浏览器、大屏H5
**特点**：左侧固定240px导航 + 右侧网格内容，多列卡片布局

### 3.2 手机端面临的问题

| 问题 | 原因 |
|------|------|
| 240px侧边栏在手机屏占比过大 | 手机宽度320-428px，侧边栏占40-75% |
| 多列卡片网格无法展示 | 手机屏无法同时展示2-3列卡片 |
| 固定定位遮挡内容 | fixed侧边栏在小屏上影响操作 |
| 导航层级过深 | 平板的平铺导航不适合手机操作逻辑 |

### 3.3 手机端设计策略

**核心原则**：

1. **导航下沉**：固定侧边栏 → 顶部导航胶囊 + 侧边抽屉弹窗
2. **内容全宽**：margin-left:240px → 全屏宽度，padding调整
3. **卡片单列**：多列网格 → 单列卡片流
4. **底部TabBar**：使用原生 tabBar，高频功能底部导航
5. **操作简化**：减少同时展示的信息量，增加层级跳转

### 5.2 条件编译策略

**原则**：

- App/H5 现有代码**不修改**原有逻辑
- 小程序端特有代码用 `#ifdef MP-WEIXIN` 包裹
- App/H5 共享代码用 `#ifndef MP-WEIXIN` 或直接使用

**示例1：layout.vue 处理**

```vue
<template>
  <!-- #ifndef MP-WEIXIN -->
  <!-- App/H5 平板端：左右布局（保持不变） -->
  <view class="layout">
    <StudentSidebar :activeItem="currentPage" @navigate="switchPage" />
    <view class="content-area">
      <component :is="currentComponent" />
    </view>
  </view>
  <!-- #endif -->

  <!-- #ifdef MP-WEIXIN -->
  <!-- 微信小程序端：layout.vue 不在 pages.json 中注册，此分支不会渲染。
       小程序端每个页面独立管理 MpNavBar + MpDrawer，
       抽屉导航通过 uni.navigateTo / uni.switchTab 实现页面跳转。 -->
  <view />
  <!-- #endif -->
</template>
```

> **说明**：UniApp 小程序端不支持 Vue 运行时 `<component :is>` 动态组件。小程序端每个 tabBar 页面（mp-home / wrongbook / growth）独立管理自己的导航栏和抽屉，抽屉中的导航项通过 `uni.navigateTo()`（非 tabBar 页面）或 `uni.switchTab()`（tabBar 页面）跳转。

### 7.1 scan.ts（扫码工具）

```typescript
// utils/scan.ts

/**
 * 封装扫码功能，从组件中抽离 wx.scanCode 等平台API调用。
 */
export function scanCode(): Promise<{ result: string; scanType: string }> {
  return new Promise((resolve, reject) => {
    // #ifdef MP-WEIXIN
    wx.scanCode({
      onlyFromCamera: false,
      scanType: ['qrCode', 'barCode'],
      success: (res) => {
        resolve({ result: res.result, scanType: res.scanType })
      },
      fail: (err) => {
        reject(err)
      },
    })
    // #endif

    // #ifdef APP-PLUS
    uni.scanCode({
      onlyFromCamera: false,
      success: (res) => {
        resolve({ result: res.result, scanType: res.scanType })
      },
      fail: (err) => {
        reject(err)
      },
    })
    // #endif

    // #ifdef H5
    // H5 环境不支持原生扫码，引导用户手动输入
    reject(new Error('H5 环境不支持扫码，请手动输入作业码'))
    // #endif
  })
}

/**
 * 解析扫码结果，提取短码。
 */
export function parseShortCode(scanResult: string): string | null {
  const raw = String(scanResult || '').trim()
  // 匹配 /hw/{code}，允许 query/hash，统一大写
  const hwMatch = raw.toUpperCase().match(/\/HW\/([ABCDEFGHJKMNPQRSTUVWXYZ23456789]{6})(?:[/?#]|$)/)
  if (hwMatch) return hwMatch[1]

  // 纸质码解析应由 parsePaperCode 使用，不能丢失学生码和页码
  const paperMatch = raw.toUpperCase().match(/\/PAPER\/([ABCDEFGHJKMNPQRSTUVWXYZ23456789]{8})\/([ABCDEFGHJKMNPQRSTUVWXYZ23456789]{6})\/P(\d+)(?:[/?#]|$)/)
  if (paperMatch) return paperMatch[2]

  // 纯6位短码
  if (/^[ABCDEFGHJKMNPQRSTUVWXYZ23456789]{6}$/i.test(raw)) return raw.toUpperCase()

  return null
}

export function parsePaperCode(scanResult: string) {
  const match = String(scanResult || '').trim().toUpperCase().match(
    /\/PAPER\/([ABCDEFGHJKMNPQRSTUVWXYZ23456789]{8})\/([ABCDEFGHJKMNPQRSTUVWXYZ23456789]{6})\/P(\d+)(?:[/?#]|$)/,
  )
  if (!match) return null
  return { studentCode: match[1], missionCode: match[2], pageNo: Number(match[3]) }
}
```

### 7.2 wechat-auth.ts（微信登录工具）

```typescript
// utils/wechat-auth.ts

import { post } from './request'

export async function wxLogin(): Promise<{
  needBindPhone: boolean
  token?: string
  userInfo?: any
  bindToken?: string
}> {
  return new Promise((resolve, reject) => {
    // #ifdef MP-WEIXIN
    wx.login({
      success: async (loginRes) => {
        try {
          const res = await post('/auth/wechat-login', { code: loginRes.code })
          if (res.code === 0) {
            if (res.data.need_bind_phone) {
              resolve({
                needBindPhone: true,
                bindToken: res.data.bind_token,
              })
            } else {
              uni.setStorageSync('accessToken', res.data.access_token)
              uni.setStorageSync('refreshToken', res.data.refresh_token)
              uni.setStorageSync('userInfo', res.data.user)
              resolve({
                needBindPhone: false,
                token: res.data.access_token,
                userInfo: res.data.user,
              })
            }
          } else {
            reject(new Error(res.message || '微信登录失败'))
          }
        } catch (e) {
          reject(e)
        }
      },
      fail: reject,
    })
    // #endif

    // #ifndef MP-WEIXIN
    resolve({ needBindPhone: true })
    // #endif
  })
}
```

## 八、微信登录后端实现

### 8.1 后端视图

```python
# apps/accounts/wechat_views.py

import requests
import secrets
from django.conf import settings
from django.core.cache import cache
from rest_framework.decorators import api_view, permission_classes
from rest_framework.permissions import AllowAny
from rest_framework.response import Response
from .models import UserAccount, WechatIdentity
from .serializers import ProfileSerializer
from .services import generate_tokens, verify_code, get_or_create_user

WECHAT_APPID = settings.WECHAT_MP_APPID
WECHAT_SECRET = settings.WECHAT_MP_APPSECRET


@api_view(['POST'])
@permission_classes([AllowAny])
def wechat_login(request):
    """微信小程序登录。"""
    code = request.data.get('code')
    if not code:
        return Response({'code': 400, 'message': '缺少code参数'})

    # 用 code 换取 openid
    resp = requests.get(
        'https://api.weixin.qq.com/sns/jscode2session',
        params={
            'appid': WECHAT_APPID,
            'secret': WECHAT_SECRET,
            'js_code': code,
            'grant_type': 'authorization_code',
        }, timeout=5,
    )
    data = resp.json()
    openid = data.get('openid')

    if not openid:
        return Response({'code': 400, 'message': '微信登录失败'})

    identity = WechatIdentity.objects.select_related('user').filter(
        appid=WECHAT_APPID, openid=openid,
    ).first()
    user = identity.user if identity else None

    if user:
        # 已绑定：直接返回 token
        tokens = generate_tokens(user)  # ← 调用现有 services.py 中的函数
        return Response({
            'code': 0,
            'data': {
                'access_token': tokens['access_token'],
                'refresh_token': tokens['refresh_token'],
                'user': {
                    'id': str(user.id),
                    'display_name': user.display_name,
                    'role_type': user.role_type,
                    'mobile': user.mobile,
                    'need_bind_phone': False,
                }
            }
        })
    else:
        # 未绑定：openid/session_key 只保存在服务端短期缓存，前端只拿一次性令牌
        bind_token = secrets.token_urlsafe(32)
        cache.set(
            f'wechat_bind:{bind_token}',
            {'appid': WECHAT_APPID, 'openid': openid, 'session_key': data.get('session_key', '')},
            timeout=600,
        )
        return Response({
            'code': 0,
            'data': {
                'need_bind_phone': True,
                'bind_token': bind_token,
            }
        })


@api_view(['POST'])
@permission_classes([AllowAny])
def wechat_bind_phone(request):
    """用一次性 bind_token + 短信验证码绑定已有手机号。"""
    bind_token = request.data.get('bind_token')
    mobile = request.data.get('mobile')
    verify_code_value = request.data.get('verify_code')
    role_type = request.data.get('role_type', 'student')
    pending = cache.get(f'wechat_bind:{bind_token}') if bind_token else None
    if not pending or not mobile or not verify_code_value or role_type not in ('student', 'parent'):
        return Response({'code': 400, 'message': '绑定参数无效'}, status=400)
    if not verify_code(mobile, verify_code_value):
        return Response({'code': 400, 'message': '验证码错误或已过期'}, status=400)
    user = get_or_create_user(mobile, role_type=role_type)
    WechatIdentity.objects.update_or_create(
        user=user,
        defaults={'appid': pending['appid'], 'openid': pending['openid']},
    )
    cache.delete(f'wechat_bind:{bind_token}')
    return Response({'code': 0, 'data': {**generate_tokens(user), 'user': ProfileSerializer(user).data}})
```
