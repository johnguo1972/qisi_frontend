## 1. 部署内容

本次发布使用当前工作区代码构建后端发布包和 UniApp H5 构建包，覆盖学生端引导答题、做题、关卡/首页刷新、错题本及同类题练习等功能。

### 后端代码

- `apps/study/guidance_views.py`：按路由模式处理固定式/非固定式引导，支持降级后的固定引导会话继续答题。
- `apps/study/serializers.py`、`apps/study/student_urls.py`：学生端引导和答题接口数据及路由。
- `apps/wrongbook/serializers.py`：错题题型、题目内容、选项及公式文本的规范化返回，未知题型使用中文兜底文案。
- `apps/missions/serializers.py`、`apps/missions/views.py`、`apps/missions/urls.py`：关卡数据、答题完成度和学生端刷新相关接口。
- `apps/knowledge/models.py`、`apps/knowledge/htmx_urls.py`、`apps/knowledge/migrations/0001_initial.py`：知识库相关模型/路由调整。
- `apps/papers/views.py`、`apps/papers/urls.py`：试卷相关接口调整。
- `config/urls.py`：后端路由注册调整。
- `apps/common/ai/tests/conftest.py`、`apps/knowledge/templates/`：随代码包一并发布的测试辅助及模板文件。

### 前端代码和构建产物

- `uniapp/src/pages/student/guidance.vue`：固定/非固定引导按 `mode` 展示；内容区可滚动，底部操作区不会遮挡；非固定引导输入框及结束状态优化。
- `uniapp/src/pages/student/answer.vue`：做题页内容区滚动、答案布局及返回后的刷新通知；题目和答案区域更紧凑。
- `uniapp/src/pages/student/mission.vue`、`home.vue`、`layout.vue`：页面重新进入/返回时自动刷新任务、关卡和首页数据。
- `uniapp/src/pages/student/wrongbook.vue`：错题列表展示题号、题型和题目内容，题号与题目内容同一行布局，未知题型显示“未识别”。
- `uniapp/src/pages/student/wrongbook-variants.vue`、`variant-practice.vue`：同类题练习中的中文题型文案、LaTeX 公式显示及内容滚动优化。
- `uniapp/src/api/student.ts`、`missions.ts`：学生端刷新及关卡数据接口调用调整。
- `uniapp/src/App.vue`、`components/QuestionAIControls.vue`、`components/StudentSidebar.vue`：全局布局、浮动控件及学生端显示调整。
- `uniapp/package.json`：前端依赖/构建配置调整。
- `uniapp/dist/build/h5/`：通过 `npm run build:h5` 生成并部署的生产 H5 文件。
