# 大压缩包题库服务器端分片导入指南

> 适用场景：JSON 题库 ZIP 超过前端 50 MB 限制，或题目数量较大。  
> 服务器：`42.194.195.78`，用户：`ubuntu`  
> 后端目录：`/mnt/datadisk0/qisi/backend`

## 一、处理流程

```text
本地大 ZIP → SCP 上传服务器 → 服务器端读取 JSON → 每 50 题处理
→ 数据库幂等写入 → 图片写入媒体目录 → 输出导入日志
```

不需要通过前端页面逐批上传，也不受接口单文件 50 MB 限制。

当前使用的管理命令：

```bash
python manage.py import_large_question_zip
```

## 二、服务器目录

原始 ZIP 临时目录：`/mnt/datadisk0/qisi/import_staging`  
导入日志目录：`/mnt/datadisk0/qisi/logs`  
数据库备份目录：`/mnt/datadisk0/qisi/backups`

不要将原始大 ZIP 长期放在 `backend/media` 中。

## 三、导入前检查与备份

检查服务器空间：

```bash
ssh -i ~/.ssh/id_rsa ubuntu@42.194.195.78 "df -h /mnt/datadisk0"
```

正式导入前备份题目、选项、图片、精选和篮子：

```bash
ssh -i ~/.ssh/id_rsa ubuntu@42.194.195.78 "mkdir -p /mnt/datadisk0/qisi/backups && sudo docker exec app-pgsql pg_dump -U appuser -d appdb -t public.tiku_exam_question -t public.tiku_question_option -t public.tiku_question_image -t public.tiku_favorite -t public.tiku_question_basket > /mnt/datadisk0/qisi/backups/question_import_before_YYYYMMDD_HHMMSS.sql"
```


## 六、正式导入

前台运行（适合少量测试）：

```bash
python manage.py import_large_question_zip \
  "/mnt/datadisk0/qisi/import_staging/初中物理题库（1.4万）.zip" \
  --subject physics --chunk-size 50
```

大题库建议后台运行：

```bash
nohup python manage.py import_large_question_zip \
  "/mnt/datadisk0/qisi/import_staging/初中物理题库（1.4万）.zip" \
  --subject physics --chunk-size 50 \
  > /mnt/datadisk0/qisi/logs/large_question_import_YYYYMMDD.log 2>&1 &
```

查看任务和日志：

```bash
pgrep -af import_large_question_zip
tail -f /mnt/datadisk0/qisi/logs/large_question_import_YYYYMMDD.log
```

日志示例：

```text
processed=500 created=480 updated=20 failed=0
```

## 七、重复题目处理规则

程序采用幂等导入，不要先删除原有题目。

| 情况 | 处理方式 |
|---|---|
| 题目不存在 | 新建题目并生成 UUID |
| 存在相同 `qid` | 更新内容并保留原 UUID |
| 没有 `qid` 但题干相同 | 按科目和题干匹配并更新 |
| JSON 无效 | 记录失败，不影响其他题目 |
| 图片找不到 | 记录警告，题目仍可导入 |

更新题目不会删除精选和篮子关系。

## 八、不同科目导入

```bash
python manage.py import_large_question_zip /path/physics.zip --subject physics --chunk-size 50
python manage.py import_large_question_zip /path/math.zip --subject math --chunk-size 50
```

每次必须使用正确的 `--subject`，否则题目不能正确出现在对应科目题库中。

## 九、导入后校验

检查题目数量：

```bash
sudo docker exec app-pgsql psql -U appuser -d appdb -c "SELECT subject, parse_status, COUNT(*) FROM public.tiku_exam_question WHERE parse_status = 'large_json_import' GROUP BY subject, parse_status;"
```

检查图片数量：

```bash
sudo docker exec app-pgsql psql -U appuser -d appdb -c "SELECT COUNT(*) FROM public.tiku_question_image WHERE file_path LIKE 'exams/large_imports/%';"
```

检查题目接口：

```text
/api/v1/questions/?subject=physics&page=1&page_size=20
```

检查知识树接口：

```text
/api/v1/teacher/knowledge-tree/?subject=physics
```

还应在前端确认题干、图片、科目、未分类节点和知识点筛选均正常。

## 十、失败、重试和恢复

查看日志：

```bash
tail -n 100 /mnt/datadisk0/qisi/logs/large_question_import_YYYYMMDD.log
```

程序支持幂等执行，可以重新运行相同命令，不会重复创建已经成功导入的题目。

如确需恢复备份：

```bash
sudo docker exec -i app-pgsql psql -U appuser -d appdb < /mnt/datadisk0/qisi/backups/question_import_before_YYYYMMDD_HHMMSS.sql
```

恢复前必须确认备份文件和目标数据库，避免覆盖导入后的新数据。

## 十一、清理临时文件

确认导入统计、图片、题目接口和知识树均正常后，再删除 ZIP：

```bash
rm -f "/mnt/datadisk0/qisi/import_staging/初中物理题库（1.4万）.zip"
```

建议保留导入日志和数据库备份。

## 十二、注意事项

- 不要通过浏览器上传 900 MB 以上 ZIP。
- 不要执行原始 SQL 中的 `DROP TABLE`。
- 不要通过删除整张题目表来处理重复数据。
- 不要在导入期间重启数据库容器。
- 正式导入前必须执行 `--dry-run`。
- 默认每批 50 道题，除非确认服务器性能，否则不要一次处理数千道题。
- 导入完成后再批量执行 AI 知识点关联。
