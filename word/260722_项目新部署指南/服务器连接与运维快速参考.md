| 参数 | 值 |
|------|-----|
| 主机 | `localhost`（容器内`postgres`） |
| 端口 | `5432` |
| 库名 | `appdb` |
| 用户 | `appuser` |
| 密码 | `pgsql!1804pwd` |

### 4.2 常用数据库命令

```bash
# 从宿主机连接
psql -h localhost -p 5432 -U appuser -d appdb

# 从容器内连接
sudo docker exec -it app-pgsql psql -U appuser -d appdb

# 执行SQL文件
sudo docker exec -i app-pgsql psql -U appuser -d appdb < file.sql

# 备份数据库
sudo docker exec app-pgsql pg_dump -U appuser appdb > backup_$(date +%Y%m%d).sql

# 备份单表
sudo docker exec app-pgsql pg_dump -U appuser -d appdb -t public.table_name > table_backup.sql

# 恢复数据库
sudo docker exec -i app-pgsql psql -U appuser -d appdb < backup.sql
```

### 4.3 Redis连接

```bash
# 从宿主机连接
redis-cli -h localhost -p 6379 -a redis172pwd

# 从容器内连接
sudo docker exec -it qisi-redis redis-cli -a redis172pwd

# 测试连接
redis-cli -h localhost -p 6379 -a redis172pwd ping
# 应返回 PONG
```

## 六、部署流程

### 6.1 后端代码更新

```bash
# 1. 本地打包（Windows Git Bash）
cd D:\yangtze\project\2026\qisi\qisi_frontend
tar --exclude=venv --exclude=node_modules --exclude=.git --exclude=__pycache__ \
    --exclude=word --exclude=uniapp --exclude=.claude --exclude=*.tar.gz \
    -czf qisi_backend.tar.gz .

# 2. 上传到服务器
scp -i ~/.ssh/id_rsa qisi_backend.tar.gz ubuntu@42.194.195.78:/mnt/datadisk0/qisi/backend/

# 3. 在服务器上解压并部署
ssh -i ~/.ssh/id_rsa ubuntu@42.194.195.78 "
  cd /mnt/datadisk0/qisi/backend
  cp -r . ../backend_\$(date +%Y%m%d_%H%M%S)  # 备份
  tar -xzf qisi_backend.tar.gz
  rm qisi_backend.tar.gz
  
  source venv/bin/activate
  pip install -r requirements.txt -q
  python manage.py migrate --noinput
  python manage.py collectstatic --noinput
  
  sudo systemctl restart qisi-gunicorn qisi-celery qisi-celery-beat
"
```

### 6.2 前端H5更新

```bash
# 1. 本地构建
cd D:\yangtze\project\2026\qisi\qisi_frontend\uniapp
npm run build:h5

# 2. 上传到服务器
scp -i ~/.ssh/id_rsa -r uniapp/dist/build/h5/* \
  ubuntu@42.194.195.78:/mnt/datadisk0/qisi/frontend-h5/
```

### 6.3 数据库迁移


## 八、常见问题排查

### 8.1 API返回502

```bash
# 检查gunicorn是否运行
sudo systemctl status qisi-gunicorn

# 检查Nginx代理地址
cat /opt/qisi/nginx.conf | grep proxy_pass
# 应为: proxy_pass http://172.18.0.1:8001/api/;
```

### 8.2 API返回404

```bash
# 检查Nginx proxy_pass是否带路径
# location /api/ 块中 proxy_pass 末尾必须带 /api/
```

### 8.3 数据库连接失败

```bash
# 测试连接
psql -h localhost -p 5432 -U appuser -d appdb -c "SELECT 1;"

# 检查容器状态
sudo docker ps | grep app-pgsql
```

### 8.4 Redis连接失败

```bash
# 测试连接
redis-cli -h localhost -p 6379 -a redis172pwd ping
# 应返回 PONG
```

### 8.5 Nginx无法启动

```bash
# 确认证书文件存在
ls -la /mnt/datadisk0/docker/volumes/qisi-certbot-certs/_data/live/qisi.chengxuelu.com/
# 应看到 fullchain.pem 和 privkey.pem

# 检查Nginx配置语法
sudo docker exec qisi-nginx nginx -t
```
